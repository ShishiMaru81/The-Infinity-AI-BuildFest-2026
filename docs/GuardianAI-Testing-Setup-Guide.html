Legal: Keep Demo / Test Mode ON. False reports to 999 may be a criminal offense under Bangladesh law.

5. Gmail app password

  1. Google Account → Security → 2-Step Verification ON
  2. Create App password (Mail)
  3. Paste into SMTP_PASS

6. Start commands

Terminal 1:  .\start-backend.ps1
Terminal 2:  .\start-frontend.ps1
Browser:     http://localhost:3000

7. Five-minute test

  1. Confirm Demo / Test Mode in header
  2. Start Webcam → show knife ~5 seconds
  3. Modal opens → Confirm & Dispatch
  4. Check TEST_EMAIL inbox
  5. Verify backend/dispatch_log.json has "mode": "test"
  6. Try False Alarm once

8. Troubleshooting

ProblemFix
No emailSMTP app password; restart backend
No boxesLighting; threshold 0.5; knife prop
No modalHold longer; consecutive frames = 3
Email to 999APP_MODE=test + Test Mode UI
Summary: Test mode ON + SMTP + TEST_EMAIL + both servers + webcam + knife. Nothing else required.
